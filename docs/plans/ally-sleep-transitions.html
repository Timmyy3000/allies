Ownership

One player owns time. Hosts own presentation inputs and lifecycle.

Player

Owns elapsed time, active/private phase, latest request, sampled sleep pose, WAAPI and SVG SMIL seeking, and coherent endpoints. It owns no product data and makes no network request.

Web adapter

Creates srcDoc once per shape, posts state/reduced/pause changes, and observes intersection. The opaque sandbox accepts messages only from its parent window.

Mobile adapter

Keeps current sizing, color shell, and label contracts. It pauses from list viewability, conversation scroll position, route focus, and AppState. Reduced motion uses a generated same-state static SVG; a terminated content process reloads once, then uses that static fallback.

Motion contract

Latest request wins after a coherent endpoint.

Durations: idle 4000 ms, thinking 4502.083 ms, sleeping 9600 ms, waking and falling-asleep 1400 ms. Waking follows a 420 ms pose bridge, about 1820 ms total.

Private phaseAny public stateComplete the current private phase. If direction reversed, traverse the opposite phase instead of cutting between unrelated poses.
Reduced motionAny public stateSwitch immediately to a static pose: idle/sleeping at their stable start and thinking at the approved midpoint. Schedule no RAF or bridge.
Paused/hidden/backgroundedAny stateRetain state and elapsed time but schedule no RAF. Resume with zero first-frame delta, without replaying wall time.

Inactivity owner

Web retains isAllySleeping(ally, latestMessage, now, recentActivityAt), its ten-minute threshold, and 30-second clock. Mobile adds the same pure predicate beside conversation-state helpers. Sleep requires a bound Ally, a finite latest-message timestamp, and no newer activity. Non-whitespace draft edits refresh recent activity; whitespace-only changes do not. A newly accepted message provides a persisted timestamp. No message means no sleep.

Failure and accessibility

Invalid appearance retains the visible ? placeholder. Reduced motion uses an exported static SVG for the same shape/state. A terminated native content process reloads once, then uses that static image after another failure. Shell, name, and controls remain usable. Unknown states use idle; no shape substitutes for another.

Security boundary

Only inspected, checked-in SVGs enter the generated document. Serialized configuration escapes <. Web grants sandbox scripts without same-origin capability. Mobile loads HTML locally, accepts updates only through its adapter, blocks navigation away from the initial local document, and disables scrolling and interaction. Neither adapter loads a remote script, image, stylesheet, or font.

Acceptance

Behavior is complete only when continuity, inactivity, and accessibility all hold.

  1. Each shape renders approved idle, refined thinking, and sleeping loops locally on web and mobile.
  2. Idle/thinking waits for the neutral boundary without restart or stutter.
  3. Sleep entry completes awake, plays falling-asleep for 1.4 seconds, then loops sleep.
  4. Wake promptly samples sleep, bridges about 420 ms, plays the full 1.4 s authored waking beat, and enters the latest awake request after about 1.82 s total.
  5. Rapid requests retain one latest public state and reverse only through coherent endpoints.
  6. Reduced motion switches immediately to a distinct static requested pose with no continuous animation or bridge.
  7. Web sleep still requires a bound Ally, latest message, and ten inactive minutes; Machine state is irrelevant.
  8. Mobile matches that predicate and wakes on meaningful draft activity or active conversation work.
  9. Web sandbox/CSP and mobile local WebView make no asset/script request and allow no remote navigation.
  10. Hidden/offscreen web and offscreen, scrolled-away, unfocused, or backgrounded mobile freeze; inline thinking pauses away from latest and list mounts stay bounded.
  11. Reduced motion and a repeat native process failure after one reload use a same-shape/same-state exported static SVG.
  12. Appearance validation, shell color/size, labels, onboarding defaults, chat controls, and conversation behavior remain intact.
