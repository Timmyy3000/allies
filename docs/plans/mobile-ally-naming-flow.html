Implementation tasks

Acceptance checklist

The implementation is ready for review when every item is observable in the app or in command evidence.

  • Welcome CTA opens the naming screen.
  • Back circle is 40px and #F3F3F3.
  • Chevron uses the supplied asset.
  • Heading uses Open Runde, 24px, -1px tracking, 24px line height.
  • Input uses Open Runde, 28px, -1px tracking, centered.
  • Typed name uses the current accent color.
  • Disabled Next is #D9D9D9 with white text.
  • Active Next uses the current accent color.
  • Button sits 50px above the physical bottom.
  • Name ring is empty; color preview ring is partially filled.
  • Back resets progress and preserves name/accent.
  • Central Allies logo remains orange.
  • bun run lint:mobile passes.
  • bun --filter mobile typecheck passes.
  • git diff --check passes.

Risks & mitigations

Shared dirty checkout

Execute in an isolated workspace, stage only feature files, and never reset or clean the other agents’ changes.

SVG platform variance

Use Expo Image’s local SVG support first; fall back to the same path in a tiny SVG component only if the native build requires it.

Accent drift

Pass one flow-owned color into dynamic surfaces and leave the logo’s orange constant untouched.
