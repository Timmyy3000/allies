Allies mobile · implementation plan

Mobile Cloud API parity

Reconnect the existing native visual experience to the shared Cloud contracts so mobile reaches web-level behavior. Waitlist is intentionally excluded.

Outcome

Onboarding, durable Ally roster, account/session continuation, and conversation behavior use the typed Cloud client. Native navigation, bearer transport, encrypted storage, polling, and presentation stay platform-specific.

Scope

  • Remove the mock provider from the production runtime.
  • Preserve onboarding attempts and replies through Google sign-in, then create with stable idempotency.
  • Use the durable workspace Ally collection, account/profile operations, conversation pagination, message retries, and shared activity projection.
  • Out of scope: every waitlist route and API on mobile.

Phases

1 · Reconnect real Cloud boundaries

Remove the mock provider, complete the native sign-in return path, add the exact retry bearer allowlist entry, wire onboarding creation, roster queries, appearance normalization, and account/profile support.

2 · Match conversation behavior

Use typed conversation queries, immutable-ID history merging, encrypted pending sends, replay-safe acceptance, retry actions, bounded foreground activity polling, shared projection, terminal refetch, and reconciliation messaging.

3 · Verify and document

Run focused tests, mobile lint/typecheck, relevant shared checks, and keep the README and Nabu implementation handoff synchronized. Scan for accidental waitlist or mock runtime paths.

Acceptance criteria

  1. Creation survives sign-in and completes once with stable idempotency.
  2. Roster data comes from the durable workspace collection.
  3. Conversation history, replayed sends, uncertain sends, retries, terminal states, and permanent gaps are safe and visible.
  4. Activity polling is focused, bounded, abortable, and stops at terminal/error states.
  5. No waitlist API or route is used by mobile.
  6. Account/profile/avatar operations use the shared Cloud client and native session boundary.
