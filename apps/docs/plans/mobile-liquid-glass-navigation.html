Mobile Liquid Glass and Home Navigation Pill

Native iOS liquid glass effect for controls and a unified floating navigation pill on the Allies home screen, with clean muted button fallback on Android.

Platform
Expo SDK 57 / iOS Liquid Glass & Android
Native Engine
expo-glass-effect (GlassView)
Fallback Surface
theme.controlSurface (#F3F3F3 / #161616)

Core Strategy: Leverage the already-installed expo-glass-effect for native Apple liquid glass on iOS, while preserving a theme-adaptive muted surface on Android. Unify top tabs and bottom action into a floating bottom pill.

Feature Overview

  • Implement GlassSurface wrapping GlassView on iOS, falling back to theme.controlSurface on Android.
  • Apply liquid glass to the Back button across onboarding and conversation screens.
  • Replace the top tabs (My allies, Routines) and the static bottom button on the Allies Home screen with a unified, floating liquid glass navigation pill.
  • Support tab switching between the Allies roster and a clean Routines placeholder state.

Implementation Phases

1. Shared GlassSurface Component

Create apps/mobile/src/components/ui/glass-surface.tsx. Export a container that inspects Platform.OS and renders GlassView on iOS with customizable glass effect style (default regular) and fallback container styling on Android/Web.

2. Back Button Upgrade

Enhance OnboardingHeader and MockConversationScreen back buttons to adopt GlassSurface with rounded 20px corners, maintaining responsive touch target and proper icon contrast.

3. Home Navigation Pill

Build HomeNavigationPill under apps/mobile/src/features/onboarding/home-navigation-pill.tsx. Update OnboardingAlliesScreen: remove top tabs, remove bottom fixed button, mount the pill anchored over the bottom safe-area, and connect tab state to toggle between Allies list and a clean Routines placeholder.

4. Verification

Validate with bun run typecheck:mobile, bun run lint:mobile, and bun run test:run. Confirm live reload in Metro on port 8082.

Acceptance Criteria

  1. Native iOS liquid glass effect is rendered via expo-glass-effect on Apple devices.
  2. Android displays a matching muted surface utilizing theme.controlSurface.
  3. Back buttons in onboarding and conversation headers feature liquid glass styling.
  4. Allies Home screen contains a floating navigation pill replacing the old top tabs and bottom button.
  5. Tapping "Make an Ally" triggers ally creation; tapping "Allies" and "Routines" toggles views.
  6. All existing and new tests pass with zero regressions.
